Everything an agent needs to actually do the work

Not just chat — Houston reads, edits, searches, and runs your code, with you in the loop on every consequential step.

Any model, your keys

Claude, GPT, Gemini, any OpenAI-compatible endpoint, and local models via Ollama or LM Studio. The picker shows each model's context window and capability badges, read live from the host.

Agentic tool use

Read, write, edit, patch, search, run shell, inspect git, fetch and search the web, and drive pull requests. Pure reads run concurrently; anything that writes or runs stays sequential.

Approval-gated and sandboxed

Choose plan, ask, auto, or full-auto. Every consequential action is reviewable, and where the OS supports it, shell commands run confined to a best-effort sandbox.

Structural code search

Bundled ripgrep for fast content search and ast-grep for syntax-tree matching — find calls, declarations, and JSX by shape, not by fragile regex, out of the box.

See its own localhost

After starting a dev server, the agent can load the page in a sandboxed view, screenshot it, and read the console — closing the build → look → fix loop. A live preview panel docks beside the chat.

Subagents & adversarial review

Hand focused, read-only questions to subagents with fresh context, and run a multi-agent review that checks your diff for correctness, security, and quality — then verifies its own findings.

MCP, agents & skills

Connect Model Context Protocol servers over stdio, HTTP, or SSE. Define custom read-only agents and on-demand skills with a Markdown file — Houston picks up your project's own conventions too.

Frequently asked questions

What is Houston?

Houston is a cross-platform desktop coding agent. You point it at an AI model and a project folder, and it can read, edit, search, and run code — with every consequential action gated by an approval flow, and shell commands sandboxed where the operating system supports it.

Is Houston free?

Yes. Houston is free to download and run. You bring your own model API keys, or run a local model, and pay only whatever your chosen provider charges for usage — Houston itself adds no fee.

Which AI models does Houston work with?

Claude, GPT, Gemini, any OpenAI-compatible endpoint, and local models via Ollama or LM Studio. You can switch models per conversation, and the picker shows each model's context window and capabilities.

Does Houston send my code or data anywhere?

Houston runs on your device and collects no analytics or telemetry from the app. Your data leaves your machine only when you use a feature that reaches a provider you configured (sending a prompt, searching the web, or checking for updates), and only to that destination. The one usage signal we can see is the aggregate download and update-check count our download host keeps for released files, which holds no personal data and involves no in-app tracking.

Which operating systems does Houston support?

macOS 12 Monterey or newer (Apple Silicon and Intel), Windows 10 or newer (x64), and Linux x64 (glibc 2.35+). A standalone terminal CLI also runs anywhere with Node 22 or newer.

Is it safe to let an agent run code on my machine?

You choose an approval mode — from reviewing every action, to auto-approving edits, to full autonomy — and where the OS supports it, shell commands run in a best-effort sandbox. You stay in control of what executes.

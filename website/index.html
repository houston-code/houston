Everything an agent needs to actually do the work

Not just chat — Houston reads, edits, searches, and runs your code, with you in the loop on every consequential step.

Any model, your keys

Claude, GPT, Gemini, any OpenAI-compatible endpoint, and local models via Ollama or LM Studio. The picker shows each model's context window and capability badges, read live from the host.

Agentic tool use

Read, write, edit, patch, search, run shell, inspect git, fetch and search the web, and drive pull requests. Pure reads run concurrently; anything that writes or runs stays sequential.

Approval-gated and sandboxed

Choose plan, ask, auto, or full-auto. Every consequential action is reviewable, and where the OS supports it, shell commands run confined to a best-effort sandbox.

Structural code search

Bundled ripgrep for fast content search and ast-grep for syntax-tree matching — find calls, declarations, and JSX by shape, not by fragile regex, out of the box.

See its own localhost

After starting a dev server, the agent can load the page in a sandboxed view, screenshot it, and read the console — closing the build → look → fix loop. A live preview panel docks beside the chat.

Subagents & adversarial review

Hand focused, read-only questions to subagents with fresh context, and run a multi-agent review that checks your diff for correctness, security, and quality — then verifies its own findings.

MCP, agents & skills

Connect Model Context Protocol servers over stdio, HTTP, or SSE. Define custom read-only agents and on-demand skills with a Markdown file — Houston picks up your project's own conventions too.

Install & accept

Add a key

3

Open a folder

Point Houston at a project, pick an approval mode, and start giving it work. You review the actions that matter.

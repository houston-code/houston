Side chat (/btw)

The side chat answers a quick question about the open chat without adding anything to it. Open it from the titlebar (or the command palette); it sees the chat so far and can read the project, but it cannot edit files, run commands, or reach the network, and it works while the main chat's turn is still running. Send to main puts an exchange into the main chat as a message (queued if a turn is running), and Continue in new chat forks the chat with the exchange as a draft. Its tokens count toward the chat's cost.

Each chat has one side chat, kept with the chat: closing the panel, switching to another chat, a plan review taking over the panel, or restarting Houston never loses it, and an answer still coming in keeps going and shows up when you come back. Before each follow-up it catches up on what the main chat said since the last answer. New side chat (the + in its header) clears it and starts over.

In the terminal, /btw <question> asks the same chat's side chat (shared with the desktop app's panel), and /btw clear starts it over.

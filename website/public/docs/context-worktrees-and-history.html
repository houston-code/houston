Context, worktrees, and history

  • Compaction. When a conversation grows too large, Houston first trims large tool output the agent has moved past (it can re-read anything it still needs), then summarizes the older part of the conversation, including the earlier steps of one long request, so it never overflows the context window. The request being worked on is always kept word for word. The threshold is sized automatically from the selected model's context window (a large-window model compacts later, a small local model sooner), and the summary is saved with the conversation so later turns extend it instead of re-summarizing from scratch. The full transcript stays on screen; only what is sent to the model is compacted. Set a fixed token threshold or disable it in Settings, Context window.
  • Worktrees. In a git repo, a new chat defaults to running in a fresh, isolated worktree on its own branch under .houston/worktrees/, so the agent's edits never touch the current checkout. Untick New worktree to work in the repo directly. In a repo whose current branch has no commits yet (a fresh git init), the toggle starts off; a worktree can only branch from another branch that has commits, and is not offered when no branch has any.
  • Conversations are saved per project folder. Chats can be exported as JSON or self-contained HTML and imported from either (an HTML export from an older version brings back only the chat text), searched, and forked.
  • The File menu starts a new chat (⌘N), a new chat in another folder (⇧⌘N), or one in a recent folder (Open Recent), and imports or exports chats.
  • Undo a turn's file changes. Before the agent edits a file, Houston snapshots it, so the latest turn's changes can be reverted with one click (and re-applied after a revert). This covers every file-editing tool, including multi-file patches (adds, updates, deletes, and moves) and edits made by a writable subagent the turn dispatched. Checkpoints persist on disk in your Houston profile, so the revert/redo affordance survives an app restart; the most recent 50 turns' checkpoints are kept. Shell-command side effects are not checkpointed: revert only restores files the editing tools touched.

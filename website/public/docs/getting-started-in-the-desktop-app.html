Getting started in the desktop app

On first launch, the welcome screen shows a three-step Get started checklist:

  1. Connect a model. Paste an API key for Anthropic, OpenAI, or Gemini (it's checked with a live model listing before it's saved), or point at a local Ollama or LM Studio server.
  2. Open a project folder.
  3. Send a first task. When only this step is left, the cursor moves into the message box (which glows) and the step suggests a task: "Explain how this project is organized." for a folder with files, or "Build a simple to-do list web page in this folder." for an empty one.

Each step ticks itself off from the app's real state, and the checklist goes away for good once the first task is sent.

Changing your mind. While the checklist is open, each finished step shows what it set and has a Change button, so you can switch model, provider, or folder before your first task:

  • on "Connect a model" it reopens the panel with the saved key (Replace key swaps it) and a model picker
  • on "Open a project folder" it reopens the folder picker

Tips along the way

A few one-time tips point at controls the first time they matter:

  • the approval mode, the New worktree toggle, and the message box (@ files, / commands, # rules), a couple of seconds before your first message (you can keep typing meanwhile)
  • Revert and Changes, after the first turn that edits files

Skip tips or Esc dismisses them.

Take the tour plays the tips any time, and also covers steering (see "Typing while it works"). Find it in the command palette (⌘K) or under Help → Take the Tour…. If you used Houston before this feature, nothing appears on its own.
